# Photos de la landing page

Déposez vos photos dans ce dossier. Aucune modification de code n'est
nécessaire : dès qu'un fichier porte le bon nom, il remplace automatiquement
le cadre pointillé correspondant sur la page d'accueil.

## Comment faire

1. Renommez votre photo avec l'un des noms du tableau ci-dessous.
2. Déposez-la dans `public/photos/`.
3. Publiez le site. La photo apparaît à la place du cadre.

Formats acceptés : `.webp`, `.jpg`, `.jpeg`, `.png`, `.avif`.
Le `.webp` donne les fichiers les plus légers, le `.jpg` convient très bien.

Tant qu'un fichier est absent, la page affiche le cadre pointillé avec le nom
attendu écrit dedans. Rien ne casse : vous pouvez en ajouter une à la fois.

## Conseils

- Visez 1600 px de large au minimum pour les photos en paysage, 800 px pour
  les portraits et les carrés.
- Cadrez large : les photos sont recadrées automatiquement pour remplir leur
  emplacement, le sujet doit être au centre.
- Évitez les fichiers de plus de 2 Mo, la page se chargerait lentement.
